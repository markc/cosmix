Weekly substrate notes

The property substrate landed this week, which means daemon state is now queryable as structured data rather than scraped from logs. If you have been keeping a shell alias to grep a unit file, you can retire it.

What changed

  • Namespaced properties with versioned writes.
  • A uniform *.props.* verb surface on every daemon.
  • Change streams, so nothing has to poll.

Full notes are in the substrate notes, and the migration checklist is here.

The interesting part is not that state is queryable. It is that the thing doing the querying is usually not a person.
