# Media licence and provenance

The original Cosmix media generated by this package is dedicated to the public
domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
This includes the observatory and celestial sculpture outputs and original
coastal geometry. The generating Rust/Mix/Blender scripts retain the package's
MIT code licence. CC0 is the media policy authorised by the project maintainer.

Cape Hill imagery is by Greg Zaal, distributed by Poly Haven under CC0.
See https://polyhaven.com/a/cape_hill and https://polyhaven.com/license.
Cosmix's cubemap conversion adds no restrictions. Credits are provenance,
not a new attribution requirement.

Coast Sand 03 colour and normal maps are by Rob Tuytel / Poly Haven, CC0:
https://polyhaven.com/a/coast_sand_03. The 1024-pixel derivatives preserve
that unrestricted status.

The JSON manifest records source URLs, transformations and SHA-256 hashes.
Binary originals, editable `.blend` files, exported GLBs, preview images and
videos live in the external media library, not Git. Do not silently apply this
licence to unrelated third-party material. Public mirrors are not yet deployed.
